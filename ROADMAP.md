# 🗺️ Дорожная карта развития Tabis VPN (ROADMAP)

В данном документе зафиксированы запланированные функции и архитектурные улучшения экосистемы **Tabis VPN** для будущих итераций.

---

## 📱 1. Клиентские приложения (Android / iOS / Windows)

### 1.1. Генерация QR-кодов для мгновенного подключения
- Добавление всплывающего QR-кода при создании или просмотре ключа в админке.
- Быстрое сканирование камерой через приложения Shadowrocket, V2RayTun, Streisand (iOS / iPad / macOS) без необходимости ручного копирования длинных ссылок подписки.

### 1.2. Тестирование задержки и скорости (Ping / RTT / Speedtest)
- Отображение живого пинга (RTT) в миллисекундах до активного сервера в интерфейсе Android и Windows клиентов.
- Встроенный легковесный тест скорости без необходимости переходить на сторонние сайты.

### 1.3. Раздельное туннелирование (Split Tunneling / Режим исключений)
- Возможность для пользователей выбирать конкретные приложения или доменные зоны (.ru, банковские клиенты, Госуслуги, доставка), которые должны работать напрямую без туннелирования.
- Настройка интеллектуальной маршрутизации на стороне приложения для оптимизации локального трафика и защиты внешних сетевых сессий.

### 1.4. Защитный выключатель (Kill Switch)
- Мгновенная изоляция незашифрованного сетевого трафика на клиенте при непредвиденном разрыве VPN-соединения до момента его безопасного переподключения.
- Исключение случайной утечки реального IP-адреса и незашифрованных пакетов в открытую сеть.

### 1.5. Автообновление приложений (In-App Updates)
- Автоматическая фоновая проверка версии TabisVPN.apk и TabisVPN.exe через GitHub Releases API.
- Всплывающее диалоговое окно в приложении с кнопкой «Обновить в 1 клик» при выходе новой сборки.

## ⏳ 2. Биллинг и контроль трафика (Traffic & Access Control)

### 2.1. Срок действия ключей (Expiration Date / TTL)
- Возможность указывать дату окончания действия ключа (например, 30 дней, 3 месяца, 1 год или бессрочно).
- Автоматический перевод токена в статус EXPIRED по истечении срока.
- Наглядная индикация в админке: сортировка пользователей по приближающейся дате продления.

### 2.2. Квоты трафика (Traffic Quota Limits)
- Установка лимита трафика на календарный месяц (например, 50 GB, 100 GB).
- Варианты поведения при исчерпании лимита:
  - Мягкое ограничение скорости (шейпинг до 1 Мбит/с).
  - Временная деактивация до наступления следующего расчетного периода.

## 🤖 3. Интеграция с Telegram

### 3.1. Telegram-бот администратора (Tabis Admin Bot)
- **Мгновенные алерты:**
  - Оповещение при падении Hysteria 2 или Nginx.
  - Предупреждение о критическом расходе памяти (RAM > 90%) или заполнении диска (Disk > 85%).
  - Уведомление при срабатывании защиты Fail2ban (бан подозрительного IP).
- **Управление через Telegram:**
  - Команда /newkey <Имя> — моментальная генерация нового ключа с красивым форматированием для пересылки клиенту.
  - Команда /stats — сводка: онлайн пользователей, трафик за сегодня, статус всех демонов.

### 3.2. Telegram-бот самообслуживания для пользователей
- Личный кабинет клиента по токену:
  - Проверка статуса подписки и срока действия.
  - Просмотр объема израсходованного трафика.
  - Быстрое получение свежих инструкций и ссылок на скачивание клиентов под все ОС.
