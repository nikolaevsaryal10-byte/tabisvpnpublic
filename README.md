## 💻 Подробная инструкция: Установка на Windows

### Способ 1: Установка через инсталлятор (Рекомендуется)

1. Скачайте файл [**TabisVPN_Setup.exe**](https://github.com/nikolaevsaryal10-byte/tabisvpnpublic/raw/main/TabisVPN_Setup.exe).
2. Запустите скачанный файл:
   - Если появится окно SmartScreen («Система Windows защитила ваш компьютер»), нажмите **«Подробнее»** ➔ **«Выполнить в любом случае»**.
3. В окне установщика оставьте галочки:
   - ✅ **«Запускать Tabis VPN при входе в Windows»** — приложение будет автоматически готово к работе при старте компьютера.
   - ✅ **«Создать ярлык на Рабочем столе»**.
   - ✅ **«Запустить Tabis VPN после установки»**.
4. Нажмите **«УСТАНОВИТЬ»**.
5. Приложение запустится автоматически. Введите ваш **Код доступа** (`TABIS-XXXX-XXXX`) и нажмите **«ПОДКЛЮЧИТЬ»**.

#### 🎯 Особенности приложения для Windows:
- **Работа в системном трее:** При нажатии на крестик `✕` приложение не закрывается, а сворачивается в трей (возле часов), сохраняя активное защищённое соединение.
- **Быстрый доступ:** Кликните правой кнопкой мыши по иконке со щитом Tabis в трее, чтобы быстро открыть окно или полностью выйти из программы.
- **Автозапуск:** Можно в любой момент включить или выключить переключателем *«Автозапуск при старте Windows»* прямо внизу окна программы.
- **Автообновление:** При появлении новой версии сверху отобразится баннер обновления — нажмите «СКАЧАТЬ», и приложение обновится автоматически.

## 📱 Подробная инструкция: Установка на Android

1. Нажмите на ссылку [**Скачать TabisVPN.apk**](https://github.com/nikolaevsaryal10-byte/tabisvpnpublic/raw/main/TabisVPN.apk) со смартфона.
2. Дождитесь окончания загрузки файла `.apk`.
3. Откройте скачанный файл:
   - Если система запросит разрешение: выберите **«Разрешить установку из этого источника»**.
   - Нажмите **«Установить»**.
4. Запустите приложение **Tabis VPN**.
5. При первом запуске:
   - Введите ваш персональный **Код доступа** (формата `TABIS-XXXX-XXXX`).
   - Нажмите **«Активировать»**.
6. Нажмите большую центральную кнопку **«Подключиться»**:
   - При первом включении подтвердите создание VPN-профиля Android.
7. Статус сменится на **«Подключено»** — туннель активен!

> 🔄 **Автообновление:** Приложение регулярно проверяет обновления и при выходе новой версии предлагает обновиться нажатием одной кнопки.

## 🍏 Инструкция: Настройка на iPhone / iPad (iOS)

1. Установите бесплатное приложение **V2RayTun** или **Streisand** из App Store.
2. Скопируйте персональную ссылку на подписку:
   ```text
   https://tabisvpn.site/api/v1/sub?token=ВАШ_КОД
   ```
3. В приложении нажмите `+` (Добавить подписку), вставьте ссылку и обновите конфигурации.
4. Выберите сервер Tabis VPN и включите переключатель.
