## 📱 Подробная инструкция: Установка на Android

1. Нажмите на ссылку [**Скачать TabisVPN.apk**](https://github.com/nikolaevsaryal10-byte/tabisvpnpublic/raw/main/TabisVPN.apk) со смартфона.
2. Дождитесь окончания загрузки файла `.apk`.
3. Откройте скачанный файл:
   - Если система запросит разрешение: выберите **«Разрешить установку из этого источника»** (стандартная защита Android при установке приложений не из Google Play).
   - Нажмите **«Установить»**.
4. Запустите приложение **Tabis VPN**.
5. При первом запуске:
   - Введите ваш персональный **Код доступа** (формата `TABIS-XXXX-XXXX`, выданный администратором).
   - Нажмите **«Активировать»**.
6. Нажмите большую центральную кнопку **«Подключиться»**:
   - При первом включении Android покажет запрос на создание VPN-туннеля — нажмите **«ОК»** / **«Разрешить»**.
7. Статус сменится на **«Подключено»** — туннель активен, весь трафик защищён!

> 🔄 **Автообновление:** При выходе новых версий приложение само уведомит вас прямо на главном экране и предложит обновиться в один клик.

## 💻 Подробная инструкция: Установка на Windows

### Вариант 1: Использование приложения (TabisVPN.exe)
1. Скачайте [**TabisVPN.exe**](https://github.com/nikolaevsaryal10-byte/tabisvpnpublic/raw/main/TabisVPN.exe).
2. Поместите файл в удобную папку (например, на Рабочий стол или в `C:\Program Files\TabisVPN`).
3. Запустите `TabisVPN.exe`:
   - Если Windows SmartScreen покажет предупреждение, нажмите **«Подробнее»** ➔ **«Выполнить в любом случае»**.
4. Введите ваш **Код доступа** (`TABIS-XXXX-XXXX`) и нажмите подключение.

---

### Вариант 2: Быстрая установка в 1 команду через PowerShell (Рекомендуется)
Если вам нужно мгновенно настроить туннель без ручного скачивания:
1. Откройте **PowerShell** от имени администратора.
2. Вставьте команду (замените `ВАШ_КОД` на ваш персональный ключ доступа):
   ```powershell
   irm "https://tabisvpn.site/api/v1/windows-setup?token=ВАШ_КОД" | iex
   ```
3. Скрипт сам установит сетевой модуль Hysteria 2, пропишет персональную конфигурацию и создаст ярлык **«Tabis VPN»** на вашем рабочем столе.

## 🍏 Инструкция: Настройка на iPhone / iPad (iOS)

1. Установите бесплатное приложение **V2RayTun** или **Streisand** из App Store.
2. Скопируйте персональную ссылку на подписку:
   ```text
   https://tabisvpn.site/api/v1/sub?token=ВАШ_КОД
   ```
3. В приложении нажмите `+` (Добавить подписку), вставьте ссылку и обновите конфигурации.
4. Выберите сервер Tabis VPN и включите переключатель.

## ❓ Частые вопросы и решение проблем

- **Вопрос:** *Пишет «Ключ привязан к другому устройству».*
  - **Ответ:** Действует правило безопасности: 1 ключ = 1 устройство. Обратитесь к администратору для сброса привязки или запросите дополнительный ключ.
- **Вопрос:** *Не открываются некоторые российские сайты при включенном VPN.*
  - **Ответ:** В настройках приложения включите режим «Обход локальных/RU-сайтов», чтобы доступ к российским сервисам шёл напрямую без потери скорости.
