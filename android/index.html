Инструкция по установке APK

01
Скачайте файл

Нажмите кнопку «Скачать APK». Браузер загрузит файл TabisVPN.apk в папку «Загрузки».

При первом открытии Android может запросить «Разрешить установку из этого источника». Нажмите «Да».

Откройте приложение Tabis VPN и нажмите большую синюю кнопку «Подключить». Соединение готово!
